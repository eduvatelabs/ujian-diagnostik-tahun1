# Ujian Diagnostik Tahun 1 – Kuiz Interaktif

Kuiz latihan interaktif untuk murid Tahun 1 oleh **Eduvate Labs™** (Learn • Create • Empower).

## Kandungan
- 3 set soalan (Set 1, Set 2, Set 3), 60 soalan setiap set
- 5 bahagian, jumlah 100 markah:

| Bahagian | Markah |
|---|---|
| Bahasa Melayu | 30 |
| Bahasa Inggeris | 20 |
| Matematik | 15 |
| Sains | 20 |
| Jawi | 15 |

- Pemasa 1 jam 30 minit, bacaan soalan (🔊), maklum balas segera, halaman keputusan dan semakan jawapan.

## Akses
Kuiz ini memerlukan **kod akses** (format `EDU-XXXX-XXXX`) daripada Eduvate Labs. Setiap kod aktif selama **30 hari** dari kali pertama digunakan. Demo percuma (5 soalan) boleh dicuba tanpa kod.

## Pautan terus ke set
- `.../#set-1`
- `.../#set-2`
- `.../#set-3`

## Fail
- `index.html` – aplikasi kuiz (soalan disulitkan; perlu kod akses untuk dibuka)
- `logo.png` – logo Eduvate Labs

## Cara pasang di GitHub Pages
1. Buat repository baharu di GitHub (contoh: `ujian-diagnostik-tahun1`).
2. Muat naik `index.html`, `logo.png` dan `README.md` ke repository itu.
3. Pergi ke **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, kemudian **Save**.
4. Selepas 1–2 minit, laman akan tersedia di `https://<nama-pengguna>.github.io/ujian-diagnostik-tahun1/`.

## Nota
Bahan latihan tidak rasmi. Format sebenar ujian diagnostik berbeza mengikut sekolah.
